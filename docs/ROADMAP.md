# Development Roadmap

## Milestone 0

Foundation: schema, project layout, documentation.

## Milestone 1

IR learner: capture RAW waveform bằng ESP32-S3 và xuất dữ liệu có cấu trúc.

## Milestone 2

IR analysis: nhận diện các protocol phổ biến và chuẩn hóa repeat frame.

## Milestone 3

RF capture: tích hợp CC1101, lưu RAW packet và metadata.

## Milestone 4

Signal library: API + Web UI + database.

## Milestone 5

Playback/control: phát tín hiệu theo profile thiết bị.
